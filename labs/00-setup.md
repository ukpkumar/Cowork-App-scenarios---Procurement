# Lab 00 – Setup

Do this once before any other lab.

## What you need

- A Microsoft 365 account with access to Copilot Cowork.
- The App skill (/app) enabled in your session for Part A.
- Permission to add custom skills for Part B, and to add plugins for Part C.
- A practice OneDrive or SharePoint folder you can write to.
- The practice data workbook described in [07-practice-data.md](07-practice-data.md), saved to that folder.

## Replace these placeholders

Before you paste a prompt, replace every item in square brackets.

| Placeholder | Replace with |
|---|---|
| [Company] | Your organisation's name |
| [Practice data workbook] | The name of your practice data workbook |
| [Practice folder] | The practice OneDrive or SharePoint folder |
| [Head office] | The site the practice tender covers |
| [Currency] | The currency used in your practice data |
| [Template library location] | Where the approved PowerPoint template is stored |
| [DoA approvers], [DoA levels] | Your Delegation of Authority approvers and levels |
| [Sourcing system] | Your sourcing or ERP system |
| [Screening source] | Your sanctions or financial screening source |
| [Practice Teams channel] | A Teams channel used only for practice |

## How every lab works

1. Start a new Cowork conversation for each lab, unless the lab says to continue.
2. Attach the practice workbook, or point Cowork to [Practice folder].
3. Paste the **Try this prompt**.
4. Read the plan and the list of data Cowork will access. Approve only if it matches the lab.
5. Test the result, then paste **Then try this** to refine it in plain language.
6. Tick the **Check your result** list before moving on.

## Labs without ready-made data

Labs A5–A14 include a **Create practice data** prompt. Run it first in the same conversation. Cowork builds a small fictional workbook, saves it to [Practice folder], and the app prompt then uses it.
